# djc-frontend

Frontend Difabel Jabar Connect, marketplace jasa berbasis lokasi bagi alumni penyandang disabilitas di Jawa Barat.

## Stack

React + Vite, di-deploy ke Vercel. Keputusan stack tercatat di `docs/technical/stack-comparison.md` pada repository dokumentasi.

## Status

Repository disiapkan melalui deonaja/difabel-jabar-connect#13. Fondasi aplikasi dan panduan setup lokal ditambahkan melalui deonaja/difabel-jabar-connect#14.
